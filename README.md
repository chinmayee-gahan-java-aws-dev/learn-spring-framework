# Learn Spring Framework - GameRunner

Learning Spring Boot fundamentals with in28Minutes Ranga course.

## What I built
- *GameRunner*: Core class to run different games using loose coupling
- *Games*: MarioGame, SuperContraGame, PackmanGame implementing GamingConsole interface
- *Concepts*: Dependency Injection, Inversion of Control, Spring Beans

## Tech Stack
- Java 17
- Spring Boot 3.x
- Maven

## How to Run
\`bash
./mvnw spring-boot:run
\`
